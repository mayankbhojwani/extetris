For a gentler, example-led introduction see the [Game Programmer's Manual](manual.md). For how the parts fit together see the [design document](design.md).

## Playing a game

### class `Game`

```text
One game of ExTetris: the board, the falling piece, score and speed.

Every move method returns True if it changed something, False if it
was blocked (by a wall, another piece, pause or game over).
```


**Constructor:** `Game(width=10, height=20, pieces='progressive', rng=None, start_delay_ms=1000, speedup_every=100, speedup_factor=0.9, min_delay_ms=50)`

```text
A new game, ready to play.

width, height:   board size (default 10 x 20, as in the starter).
pieces:          which pieces appear and how often. One of:
                   * a mode name: "classic", "easy", "normal",
                     "hard", "chaos" or "progressive" (default:
                     classic pieces first, harder ones as lines
                     are cleared);
                   * a PieceMix, e.g. mix(NoHole=60, OneHole=40)
                     or assistive("normal") (it sees the board);
                   * any function rng -> piece.
rng:             random.Random; pass one with a seed to replay a game.
start_delay_ms:  time between automatic one-row falls at the start.
speedup_every:   lines to clear for each automatic speed-up
                 (default 100, as in the starter).
speedup_factor:  each speed-up multiplies the delay by this.
min_delay_ms:    the delay never goes below this.
```

- **`new_game()`**: Empty the board and start again (also works after game over).
- **`set_pieces(pieces)`**: Change the piece mix; it applies from the next piece drawn.
- **`pieces_name`** (property): Name of the current piece mix, e.g. "progressive".
- **`active`** (property): True while the player can move pieces.
- **`set_paused(paused)`**: Pause (True) or resume (False). Ignored after game over.
- **`toggle_pause()`**: Pause if running, resume if paused.
- **`move_left()`**: Move the falling piece one column left.
- **`move_right()`**: Move the falling piece one column right.
- **`rotate_cw()`**: Turn the falling piece clockwise (with wall kicks).
- **`rotate_ccw()`**: Turn the falling piece anticlockwise (with wall kicks).
- **`soft_drop()`**: One row down now; locks the piece if it is already resting.
- **`hard_drop()`**: Straight to the bottom and lock immediately.
- **`drop_at(turn, col)`**: Put the falling piece, turned as `turn`, at column `col` at the top
- **`tick()`**: One step of gravity: fall one row, or lock if resting on something.
- **`speed_up(times=1)`**: Make pieces fall faster: delay x speedup_factor, `times` times.
- **`slow_down()`**: Undo one speed-up: delay / speedup_factor.
- **`render()`**: Text picture of the board with the falling piece shown as '▒'.

## Choosing pieces (mixes)

### `mix(weights=None, name='custom', **more)`

```text
A mix from weights for groups of pieces.

Keys can be a piece name ("T", "TwoHole-03"), a class name ("TwoHole"),
"classic" (the 7 normal pieces) or "all". A group's weight is shared
equally among its pieces, so NoHole=60 means 60 % of all pieces are
NoHole ones. If groups overlap, a piece gets the sum of its shares.
Names that aren't valid Python keywords go in a dict: mix({"Γ": 2}).
```

### `only(*keys, name='custom')`

```text
Every chosen piece equally likely, e.g. only("I", "O", "T").
```

### `progressive(stages=('classic', 'easy', 'normal', 'hard'), every_lines=10, name='progressive')`

```text
Use stages[0] at first, then move to the next stage every
`every_lines` lines cleared, staying on the last one.

With the defaults: classic pieces only until 10 lines, then easy, then
normal at 20 lines, and hard from 30 lines on.
```

### `mode(name_or_mix)`

```text
A PieceMix from a mode name ('easy', 'progressive', ...) or a mix.
```

```text

```


**Constructor:** `PieceMix(weight, name='custom')`

```text

```

### `assistive(base='classic', strength=1.0)`

```text

```

### `unfair(base='classic', strength=1.0)`

```text
Prefer pieces that can't be placed without leaving holes.
```

### `fair(base='classic')`

```text
Chances never depend on the board (any plain mix already behaves so).
```

### class `BoardAwareMix` (PieceMix)

```text
A mix that changes its chances to suit the board, in one of STYLES.

base:      the mix it starts from (a mode name or any PieceMix).
style:     "assistive" favours the pieces that leave the fewest new holes,
           "unfair" the ones that leave the most (a piece that fits nowhere
           counts as the worst), "fair" ignores the board.
strength:  0 to 1. At 1 only the favoured pieces can come; at 0.5 the
           others keep half their chance; 0 is the same as "fair".

The next piece is chosen when the one before it appears (so the preview can
show it), so it is judged on the board as it is at that moment.
```


**Constructor:** `BoardAwareMix(base='classic', style='assistive', strength=1.0, name=None)`

- **`probabilities(lines=0, board=None)`**: -

### `new_holes(board, info)`

```text
The fewest new holes this piece can leave on `board`, trying every turn
and column and dropping it straight down (rows it fills are cleared first,
so filling a line counts in its favour). None if it fits nowhere.
```

### `property_groups()`

```text
Every property group that holds at least one piece, e.g. 'box:3x3'
(for menus such as the designer's).
```

### class `Shape`

```text
Any piece: a read-only grid of filled squares that can be turned.
```


**Constructor:** `Shape(matrix)`

- **`matrix`** (property): Read-only boolean numpy array of the current turn.
- **`height`** (property): Rows in the current turn.
- **`width`** (property): Columns in the current turn.
- **`cells`** (property): Filled squares as (row, column) pairs, relative to the top-left.
- **`hole_profile`** (property): Holes per column if this turn landed on a flat floor.
- **`holes`** (property): Holes if this turn landed on a flat floor.
- **`box_size`** (property): Bounding box as 'long x short', e.g. '4x2'.
- **`touching`** (property): 'edges' or 'corners'.
- **`is_chiral`** (property): True if the piece has a separate mirror-image twin.
- **`rotated_cw()`**: A new piece: this one turned clockwise.
- **`rotated_ccw()`**: A new piece: this one turned anticlockwise.
- **`same_piece_as(other)`**: True if `other` is this piece in any rotation.

### class `PieceGenerator`

```text
All shapes made of `n_cells` squares joined by `touching`.

touching = "edges"   -> squares must share sides (classic Tetris pieces)
touching = "corners" -> squares may also meet only at a corner

shapes() lists each piece once per rotation class (mirror images are
separate pieces), in a fixed order, so names and settings stay stable
between runs.
```


**Constructor:** `PieceGenerator(n_cells=4, touching='corners')`

- **`shapes()`**: One matrix per piece (rotations merged), in a fixed order.
- **`free_shapes()`**: One matrix per piece with rotations AND mirror images merged.
